## Investment Analysis

For investment properties, calculate:

### Cap Rate
```
Cap Rate = (Annual NOI / Purchase Price) × 100
NOI = Gross Rent - Operating Expenses (taxes, insurance, maintenance, vacancy)
```

### Cash-on-Cash Return
```
Cash-on-Cash = (Annual Cash Flow / Total Cash Invested) × 100
Cash Flow = NOI - Mortgage Payment
Cash Invested = Down Payment + Closing Costs + Repairs
```

3. Similar age and condition
4. Sold within last 6 months (3 months preferred)
