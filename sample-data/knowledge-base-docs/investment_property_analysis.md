## Key Investment Metrics

### Cap Rate (Capitalization Rate)
**Formula:** Net Operating Income (NOI) / Purchase Price × 100

**What It Means:**
- Measures return on investment if purchased with cash
- Higher cap rate = higher return (but often higher risk)
- Austin average: 3-5% (low due to appreciation focus)

### Cash-on-Cash Return
**Formula:** Annual Cash Flow / Total Cash Invested × 100

**What It Means:**
- Measures return on actual cash invested
- Accounts for financing
- More relevant for leveraged purchases

### Gross Rent Multiplier (GRM)
**Formula:** Purchase Price / Annual Gross Rent

**What It Means:**
- Quick screening tool
- Lower GRM = better value
- Austin average: 15-18

## Investment Property Checklist

### Before Purchasing
- [ ] Verify rental income (get rent rolls, leases)
- [ ] Confirm expenses (taxes, insurance, utilities)
- [ ] Inspect property thoroughly
- [ ] Check zoning and rental regulations
- [ ] Review HOA rules (if applicable)
- [ ] Verify separate meters
- [ ] Research neighborhood rental demand

### Financial Analysis
- [ ] Calculate cap rate
- [ ] Calculate cash-on-cash return
- [ ] Run multiple scenarios (rates, rents, vacancy)
- [ ] Factor in all expenses (don't forget reserves)
- [ ] Consider tax implications
- [ ] Compare to alternative investments

### Due Diligence
- [ ] Title search
- [ ] Property inspection
- [ ] Appraisal
- [ ] Environmental assessment (if needed)
- [ ] Survey (if needed)
- [ ] Review tenant leases
